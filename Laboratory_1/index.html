Laboratory 1: Personal HTML Knowledge Base

Having studied HTML during my first year of college, I have built a solid foundation in core web development concepts. I am comfortable using fundamental structural tags such as headings, paragraphs, lists, links, and image elements. Moving into intermediate concepts, I understand modern semantic HTML5 architecture (using elements like <header>, <nav>, <main>, <section>, and <footer>), as well as creating complex interactive tables and web forms with various input controls and validation attributes. Additionally, I am familiar with essential best practices including document object tree (DOM) hierarchy, meta viewport settings for mobile responsiveness, and accessible markup using ARIA attributes and descriptive alt tags.
